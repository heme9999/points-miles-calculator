# 一家三口美国西海岸10天积分旅行预算案例分析

*重要提示：本案例中的所有现金价格、所需积分与税费均为用于演示计算逻辑的测算示例，不代表实时航司余票或动态酒店价格。实际预订请以各常客计划官网实时查询为准。*

在规划跨洋长途旅行时，机票和酒店通常占据家庭总预算的 60% 至 70%。通过合理配置航空里程与酒店积分，家庭可以在显著降低自付现金支出的同时，享受高品质的度假体验。

本案例将完整推演一家三口（2名成人 + 1名儿童）前往美国西海岸（旧金山、一号公路、洛杉矶）10天旅行的全现金基准与积分优化方案。

---

## 1. 旅行基本信息与全现金预算基准

- **行程天数**：10 天 9 晚
- **出行人员**：2 名成人 + 1 名儿童（全体旅客共 3 人）
- **目的地**：美国西海岸（旧金山 / 洛杉矶）
- **结算货币**：美元 (USD) / 人民币换算参考 (汇率 1 USD = 7.00 CNY)

### 全现金方案预算明细（全体总价）：

| 预算支出项目 | 费用说明 | 全现金金额 (USD) | 折合人民币 (CNY) |
| :--- | :--- | :--- | :--- |
| **中美往返机票** | 3人中美经济舱标准机票 | $3,600 | ¥25,200 |
| **9晚品牌酒店住宿** | 凯悦/万豪中高端酒店 | $2,700 | ¥18,900 |
| **餐饮美食** | 10天家庭餐饮与特色餐厅 | $1,500 | ¥10,500 |
| **租车与保险** | SUV 租车 10 天全险 | $700 | ¥4,900 |
| **燃油、停车与过路费** | 城市停车费与长途燃油 | $450 | ¥3,150 |
| **门票与娱乐活动** | 环球影城/迪士尼等门票 | $900 | ¥6,300 |
| **签证与境外保险** | 3人美签EVUS及高额意外险 | $300 | ¥2,100 |
| **境外电话卡 / eSIM** | 2张无限流量数据卡 | $60 | ¥420 |
| **其他应急杂费** | 纪念品与日常开销 | $300 | ¥2,100 |
| **全现金总成本** | **完全不使用任何积分** | **$10,510** | **¥73,570** |

- **全现金人均成本**：$3,503 / 人 (约 ¥24,523)
- **全现金日均成本**：$1,051 / 天 (约 ¥7,357)

---

## 2. 积分优化方案：里程与房晚抵扣

家庭持有 180,000 航空里程（通过信用卡 1:1 转点获得）以及 120,000 酒店积分，决定用于抵扣机票与酒店两大项：

### ✈️ 航空里程兑换中美往返机票
- **机票原现金价**：$3,600 (¥25,200)
- **所需航空里程**：180,000 里程 (60,000 里程/人 × 3人)
- **必须自付的税费与附加费**：$360 (约 $120/人，包括中美政府安全税与离境税)
- **机票净节省金额**：$3,600 - $360 = **$3,240** (¥22,680)
- **机票实际兑出 CPP**：`($3,240 ÷ 180,000) × 100` = **1.80 ¢/点** (约 0.126 元/点)

### 🏨 酒店积分兑换西海岸住宿
- **酒店原现金价**：$2,700 (¥18,900)
- **所需酒店积分**：120,000 积分 (平均 13,333 分/晚)
- **积分房强制附加费/度假村费**：$0 (选用凯悦积分房，全免 Resort Fee 与税费)
- **酒店净节省金额**：$2,700 - $0 = **$2,700** (¥18,900)
- **酒店实际兑出 CPP**：`($2,700 ÷ 120,000) × 100` = **2.25 ¢/点** (约 0.158 元/点)

## 3. 最终实际自付现金与费用瀑布

```
全现金基准总预算:           $10,510
- 扣减机票现金原价:         -$3,600
+ 加回奖励机票自付税费:       +$360
- 扣减酒店现金原价:         -$2,700
+ 加回酒店杂费与度假村费:       +$0
-----------------------------------------
= 最终实际自付现金:          $4,570 (¥31,990)
```

| **日均自付现金** | $1,051 | **$457** | 日常开销大幅减轻 |

## 4. 决策结论与常客策略启示

1. **税费必须预先计入现金流**：即使机票全部用里程兑换，3人仍需自付 $360 的政府强制税费。旅行前必须预留这笔现金。
2. **选择免除 Resort Fee 的常客计划**：在美国热门目的地（旧金山/夏威夷/拉斯维加斯），度假村费动辄每晚 $30–$50。凯悦（Hyatt）与希尔顿（Hilton）对纯积分房免除该费用，直接多省下数百美元。
3. **两项兑换均达到高价值区间**：机票 CPP 达到 1.80¢，酒店 CPP 达到 2.25¢，均显著高于行业保守基准线（1.2¢），是一次极为成功的家庭积分兑换。
