# 积分还是现金：我应该用积分还是现金支付？

在规划旅行时，最常见的问题之一就是：**我到底应该用积分兑换还是直接付现金？** 这个问题没有标准答案，但通过一套简单的决策框架，你可以做出最明智的选择。

## 决策框架

在积分与现金之间做选择，核心在于如何最大化辛苦攒下的积分价值，同时兼顾你的钱包。问自己以下几个问题：
1. 我手头是否有充足的现金来舒适地支付这笔费用？
2. 相比我心中对积分的基础估值，这次兑换是否划算？
3. 现金预订和积分预订的退改政策分别是什么？

## CPP 计算法 (Cents Per Point)

比较积分和现金最简单的方法就是计算 **CPP (每积分美分价值)**。
用机票或酒店的现金价格（扣除使用积分仍需支付的税费）除以所需的积分数量。

如果算出的 CPP 高于你对该积分的个人估值，那就用积分！如果低于你的估值，建议直接付现金。

## 不要忘记税费和附加费

积分兑换的机票并不是完全免费的。你仍然需要支付政府税费，甚至某些航空公司会收取高昂的燃油附加费（Carrier-imposed surcharges）。有时这些附加费高达数百美元，会大幅拉低积分的价值。在计算 CPP 时，务必从现金价格中减去这些税费。

## 机会成本（放弃的价值）

当你使用积分预订时，你将无法在这趟航班或酒店住宿中赚取新的积分。此外，现金预订通常能帮你累积高级会员的定级航段或房晚。在比较两者的价值时，应该把这部分“失去的价值”也考虑进去。

## 灵活性与取消政策

积分预订通常具有极高的灵活性。很多航空公司和酒店的常旅客计划允许你免费或以极低的费用取消积分预订并退还积分。相反，最便宜的现金票（如基础经济舱）通常是不可退款的。

## 3 个实例分析

### 实例 1：高价值兑换
* 现金价格: $1,200
* 积分成本: 30,000 里程 + $50 税费
* CPP: ($1,200 - $50) / 30,000 = 3.83 cpp
* **结论:** 果断用积分！

### 实例 2：低价值兑换
* 现金价格: $150
* 积分成本: 15,000 里程 + $10 税费
* CPP: ($150 - $10) / 15,000 = 0.93 cpp
* **结论:** 付现金，把积分留给下次更好的机会。

### 实例 3：高额附加费陷阱
* 现金价格: $800
* 积分成本: 40,000 里程 + $500 税费
* CPP: ($800 - $500) / 40,000 = 0.75 cpp
* **结论:** 付现金。高额的附加费毁掉了积分的价值。
