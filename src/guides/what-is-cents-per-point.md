# 什么是 Cents Per Point (CPP)？如何计算积分价值？

如果你刚刚接触积分和里程的世界，你一定经常看到 **CPP** 这个词。那么它到底是什么意思？

## CPP 的定义

CPP 是 **Cents Per Point (每积分美分价值)** 的缩写。它是一个用来衡量你每使用一点积分或里程，能够换取多少现金价值的指标。由于不同常旅客计划的积分价值各不相同，CPP 可以帮助我们标准化并进行跨平台的横向比较。

## 美分与美元的换算

由于现金价格通常以美元显示，而积分往往数以万计，计算 CPP 时需要将美元转换为美分。
1 美元 = 100 美分。

## 基础公式

计算 CPP 最简单的公式是：
**CPP = (现金价格，以美分计) / (所需积分数量)**

例如，一间价值 $200 的酒店房间需要 10,000 积分：
CPP = 20,000 美分 / 10,000 积分 = 2.0 CPP。

## 包含税费的准确公式

在预订积分机票时，你通常还需要支付现金税费。为了得到准确的 CPP，你必须从现金价格中减去这部分自掏腰包的费用。

**CPP = ((现金价格 - 税费及附加费) * 100) / 所需积分数量**

## 航空公司与酒店的差异

* **酒店:** 用积分预订酒店时，标准的税费几乎总是被免除的。有时度假村费（Resort Fees）也会被免除（比如希尔顿和凯悦）。
* **航空公司:** 兑换奖励机票时，你总是需要支付一定的现金税费。这可能低至美国国内航班的 $5.60，也可能高达英国航空商务舱超过 $800 的燃油附加费。

## 避免使用虚高的现金价格

计算 CPP 时最常见的错误就是使用了虚高、不切实际的现金价格。如果一张头等舱机票的现金价格是 $15,000，但你在现实中**绝对不会**花 $15,000 去买这张票，那么用这个数字计算出的 CPP 就是自欺欺人。应该始终使用你实际上愿意支付的现金价格来计算。
