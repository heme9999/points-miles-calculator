# 酒店积分值多少钱？

通常来说，给酒店积分估值比航空里程容易得多。但是，随着大型连锁酒店不断调整其常旅客计划，游戏规则也在快速变化。

## 动态定价 (Dynamic Pricing)

大多数大型连锁酒店已经放弃了固定的“兑换表 (Award Charts)”，转而采用**动态定价**。这意味着房间的积分价格会随现金价格波动。如果酒店处于旺季且现金价格高昂，所需的积分也会随之增加。这使得获得极高的“超额价值”变得困难，但更容易获得相对稳定的基础价值。

## 住四送一 (5th Night Free)

最大化酒店积分价值的最重要技巧之一，就是利用希尔顿和万豪提供给高级会员的“住五付四 (5th night free)”福利（IHG 针对特定信用卡持卡人也提供连住四晚免一晚）。用四晚的积分兑换五晚的住宿，能让你的每积分价值 (CPP) 瞬间提升 25%。

## 度假村费 (Resort Fees)

当你用现金预订酒店时，经常会被收取隐藏的“度假村费 (Resort Fees)”或“目的地费 (Destination Fees)”。
* **凯悦 (Hyatt) 和 希尔顿 (Hilton):** 在全积分兑换的住宿中，完全免除度假村费。
* **万豪 (Marriott):** 在积分兑换住宿中**不免除**度假村费。
把被免除的度假村费算进去，会大幅提升你计算出的积分价值。

## 与现金成本对比

永远记得将积分成本与包含所有税费的现金总价进行比较。标价 $200 的房间加上税费可能高达 $250，这会直接改变你的兑换价值计算。

## 凯悦、希尔顿与万豪的区别

* **凯悦 (World of Hyatt):** 目前唯一仍保留固定兑换表的主要酒店集团。其积分价值通常很高，大约在 1.7 到 2.0 美分之间。
* **希尔顿 (Hilton Honors):** 高度动态定价。积分很容易获取，但单点价值较低，通常在 0.4 到 0.5 美分左右。
* **万豪 (Marriott Bonvoy):** 完全动态定价。积分价值通常在 0.6 到 0.8 美分左右。
