# 积分估值与单位审计报告 (VALUATION UNIT AUDIT)

## 一、审计背景与历史遗留问题
在早期版本中，部分页面（尤其是首页计算器）存在单位口径不统一的风险：
- 选项中出现了 `0.35元/英里`、`0.6元/英里`、`1.2元/英里`、`2.0元/英里`。
- **实质混淆**：国际常旅客界通用的估值是美分/点（Cents Per Point, ¢/pt），例如 0.6¢、1.2¢、1.5¢、2.0¢。
- 若直接按 `1.2元/点` 输入，相当于 `17.1美分/点`（汇率 7.0），比正常合理估值高出 **14 倍**，会导致严重失真的计算决策。

## 三、修复与验证记录

1. **首页下拉情景修复**：
   - 中文版改为：`保守情景 1.2美分 (0.084元)`、`中性航空 1.5美分 (0.105元)`、`良好兑换 2.0美分 (0.140元)`、`高价值兑换 3.5美分 (0.245元)`。
   - 英文版改为：`1.2¢`、`1.5¢`、`2.0¢`、`3.5¢`。
   - 彻底清除了旧版“0.35元/英里”、“0.6元/英里”等无汇率换算的硬编码混淆。

2. **自动化防差错单元测试**：
   - 单元测试 `test/trip-cost-engine.test.js` 明确断言：
     - `1.5 ¢/pt` 转换为人民币必须严格等于 `0.105 元/点`（±0.0001），且断言不等于 `1.5 元` 或 `10.5 元`。
     - `0.6 ¢/pt` 转换为人民币必须严格等于 `0.042 元/点`，杜绝 10x 或 100x 的单位错误。
